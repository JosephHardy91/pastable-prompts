Walk through each item we've agreed to address in <file>: show the edit, and say in plain English why we're making it. Don't change the file until I say so. If we haven't agreed on the items, ask for the list first.

Read <file> before writing anything. Copy every "before" exactly from it, and take line numbers from the file as it is now, before any edit.

Part 1. One section per item, in the agreed order:
- Heading: "### N. <the edit, as an action> (<section it's in>)"
- **Why:** one short paragraph. Say what is wrong now, what goes wrong because of it for the person reading the document, what evidence shows it (a specific case, or say there is none), and why this edit is the right size.
- The edit as a diff: "-" for removed lines, "+" for added lines, two spaces for an unchanged line kept only to show where the edit goes. Show only what changes, never a whole section. If an item touches several places, label each place in the block.
- If an item needs no edit of its own, say which item covers it.
- If two items touch the same text, say which one makes the edit.
- If you considered a further edit and decided against it, say so in one sentence, with the reason.

Part 2. The same edits again, one line each, numbered to match Part 1:
N. L<line or range> — <problem>: <explanation>: "<before>" → "<after>"
For an insertion, give the line and the sentence it follows, make "before" "", and say if it starts a new paragraph. For a deletion, "after" is "". For a long "before", quote its first and last words with "…" between them. Always give "after" in full.

The edits:
- Make the smallest edit that fixes the item. Don't rewrite around it or fold in other fixes; list anything else you notice at the end.
- Use the document's own terms, names, reference style and tense, and one name for one thing.
- State each rule in one place. If an edit moves a rule, remove it from the old place in the same item.
- Each addition must make sense where it sits: nothing that points at text further down, and nothing that leans on another section to carry its effect.
- Don't add text that rules out a misreading nobody has made.
- Check every fact an addition states (a path, a line number, a quote, a figure) against its source.

The why:
- Plain words, one idea per sentence, no chains of comma clauses.
- Every "it", "this" and "they" points at one thing. When in doubt, repeat the noun.
- Say what goes wrong, not a label for it: what the reader will do, not "unclear" or "redundant".
- Give an example as an example, not as the only case.
- Don't restate the diff in prose.

At most one line before Part 1. No closing summary.
