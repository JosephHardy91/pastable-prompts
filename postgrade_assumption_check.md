1. Grep your own absolutes. Search the guidance for nothing|nowhere|never|no amount|only|both|any|all|unless|must remain. For each hit ask: what would make this false, and did I check? That single pass catches:

- "fixing API alone leaves nothing to read" → false
- "there is nowhere else the selection can move to" → false
- "both are conventions over unvalidated string columns" → false
- "No amount of work on Job, API or Analyzer" → false
- "emits nothing unless both carry data" → incomplete (missed :61)

Five of the eight misses, from one grep. These are the claims that reach past what you verified, and they're all flagged by a quantifier.

2. Cross-section consistency on load-bearing facts. Pick the ~10 facts the rubric leans on, grep each, read every hit side by side. That's what caught the Persistence DISTINCT claim and the CS/TP contradiction in this session — both were the same fact stated in two sections that had drifted. The route-neutrality one was two sentences apart and falls out of reading the section end to end.

3. Diff the guidance against what the graders actually did. For each criterion, read the per-sample rationales and ask whether the grader keyed on what the guidance says. Two findings came from exactly this:

- JtcRXzg's grader convicted a response whose facts were all accurate — the guidance says a checked basis clears the deficit
- all three 0.9700 samples withheld 0.03 on TP for the bonus item while quoting the rule that says don't deduct

You can only do this after grading.

4. Treat any near-miss a detector names as a to-fix. Don't rely on the clean verdict. Both conversions — the numeric anchor and the Communication sentence — were passages a detector quoted and then cleared. Two independent reviewers converted them, so that's a calibration gap, not bad luck.
