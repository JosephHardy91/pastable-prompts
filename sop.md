The eight grader criteria aren't SOP sections at all. They're actually acceptance criteria decomposed by dimension — one test method with eight measured attributes instead of one pass/fail. Once you see them that way, each needs the same four slots:

1. what this attribute measures — one sentence, no restating the standard
2. what a conforming response contains — artifact criteria, presence/absence
3. what nonconformance looks like — including the boundary against the neighbouring attribute
4. what is explicitly not measured here — the "does not own" line

Edits change the SOP first and the grader criteria last.

Gap analyses help make the SOP and grader criteria tight:

- SOP content with no criterion home → under-coverage. Something you know matters and aren't scoring.
- Rubric content with no SOP basis → unsupported. This is where overreach lives: "nowhere else the selection can move," the two-of-three guard list, "do not deduct" with no criterion behind it. None of those would survive a trace back to an SOP statement.
- Both cover it, and they disagree → the contradiction class. Route neutrality, the serial chain, the checked-basis trigger.
